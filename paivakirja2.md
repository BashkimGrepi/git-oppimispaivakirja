# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Github-repositorion luominen ja paikallisen repon yhdistäminen siihen oli helppoa, sillä olen koulun ohella tehnyt sitä useasti. Myös paikallisten ja etärepositoion haarojen ero ja miten fetch komento toimii tässä oli minulle myös suhteellisen helppoa, mutta tämä aihe oli minulle aikaisemmin hämmentävää. Tämä auttoi kuitenkin minua vahvistamaan taitojani mitä olen oppinut koulun varrella. 
## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| kirjoita tähän komento        | tähän lyhyt kuvaus, mitä komento tekee |
| git remote add origin (url)   | Lisää github-repositorion etärepostorioksi |
| git remove -v                 | Näyttää repositoriot |
| git push                      | Vie paikalliset muutokset etärepositorioon |
| git fetch                     | hakee etärepositorion uusimmat muutokset |
| git merge                     | Yhdistää toisen haaran muutokset kyseiseen haaraan |
